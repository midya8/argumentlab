02 / EXTENSIONS AND ACCEPTANCE

Maximal does not mean maximum.

No stable extension exists. Classical skeptical acceptance is vacuously true for every argument because there is no extension that excludes it. This does not establish acceptance in any actual position. Credulous acceptance is false. The separately named nonvacuous answer is null/inapplicable. 04 / GROUNDED AND THREE-VALUED
A fixed point is a full trace.
Start with no accepted arguments. Replace the set by every argument it defends. In a finite framework this ascending chain reaches the least fixed point, the grounded extension. This is different from intersecting preferred extensions.

In iff all attackers are out. Out iff some attacker is in. Otherwise undec: no attacker in, with at least one attacker undec. Complete extensions correspond one-to-one to these complete labellings. This is not a claim of a one-to-one correspondence for arbitrary admissible labellings.
05 / CONDITIONAL REASONING
Acceptance is not truth.
The graph omits argument content, evidence strength and the origin of an attack. An extension states what can be accepted together under a chosen formal semantics. It does not establish a factual claim, a good decision, real-world safety or the winning side of a debate.
